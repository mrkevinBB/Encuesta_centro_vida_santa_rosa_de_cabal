Ver guía rápida: ¿Cómo crear el enlace de Google Sheets en 2 minutos?
  1. Abra una hoja de cálculo nueva en Google Sheets.
  2. En el menú superior vaya a Extensiones → Apps Script.
  3. Borre el código existente y pegue el siguiente código:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  var keys = Object.keys(data);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(keys);
  }
  var row = keys.map(function(k) { return data[k]; });
  sheet.appendRow(row);
  return ContentService.createTextOutput(JSON.stringify({status: "ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
  1. Haga clic en Implementar → Nueva implementación, elija tipo Aplicación web.
  2. En "Quién tiene acceso", seleccione Cualquier persona y autorice los permisos.
  3. Copie la URL generada (termina en /exec) y péguela arriba.
¿Cómo obtener la URL y los IDs (entry.XXXXX) de mi Google Form?
  • Abra su Google Form en modo edición, haga clic en los 3 puntos (⋮) → Obtener enlace prellenado.
  • Llene respuestas de ejemplo y pulse Obtener enlace → Copiar enlace.
  • En ese enlace verá parámetros como entry.123456789=Respuesta.
  • Cambie /viewform por /formResponse en la URL principal y asigne cada entry.XXXXX abajo.
